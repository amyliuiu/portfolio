# Amy Liu — portfolio

Work-in-progress design portfolio, built with static HTML, CSS, JavaScript, and locally generated SVG artwork.

**Preview:** https://amyliuiu.github.io/portfolio/

GitHub Pages publishes the `main` branch from the repository root. `.nojekyll` keeps the site as plain static files. No build step is required.

This repository contains only the website and its shipped assets. Original recordings, local build tools, tests, and design explorations are not included.

## Work in progress
